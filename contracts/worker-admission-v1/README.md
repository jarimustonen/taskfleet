# Worker admission v1 (fleet activation contract)

State root: resolved `TASKFLEET_HOME`, otherwise `$HOME/.taskfleet` (use the **same** root on both sides). `run create` takes an OS `flock` shared lease on `<root>/.worker-admission.lock` before idempotency lookup/reclaim, staging, native worktree materialization, and child publication. The lock file is permanent: never delete or replace it while Taskfleet processes may run. It is released after create returns, including error paths. New creation waits at most 10 seconds and returns structured stderr `error.code=admission_busy` (exit 2) on contention. Dry-run does not acquire it or create state.

Trusted fleet caller: stage the new binary in a separate path first, then invoke the **currently active admission-aware Taskfleet binary**:

```
taskfleet --json run upgrade-lock --wait-secs 10 -- /path/to/trusted-activation-program arg1 ...
```

`--wait-secs` accepts 0–600 (default 10); timeout produces `admission_busy`, exit 2. `--command-timeout-secs` accepts 1–3600 (default 600); on expiry the immediate activation child is killed and the CLI reports `upgrade_command_timeout`. A timed-out activation may have partially modified the installation: inspect and roll back under a new gate before retrying. The program is an argv executable (no shell parsing), and must perform binary and bundled-skill replacement, verification and rollback **synchronously**, reporting failure via nonzero exit. Its stdout is sent to Taskfleet's stderr; on success stdout is an envelope with `data.quiescent=true`, `data.checked_runs` and `data.command_exit=0`. On activation failure stderr carries `upgrade_command_failed` and exit 2; caller owns verification/rollback, never infer success from an interrupted command. The child inherits the exclusive lock descriptor across exec; if the Taskfleet wrapper crashes, the activation child retains the lease until it exits. This is a trust boundary, not a sandbox: pass only a controlled fleet program, not agent-generated commands. Do not spawn a detached updater from it or reenter `run create` while holding the gate.

Under exclusive admission, Taskfleet scans every published run with its per-run lock. Pending/running/blocked runs, live recorded workers or supervisors, and unfinished merge transactions refuse with `upgrade_not_quiescent` and `error.details.run_ids`, exit 2. Settled failed/cancelled runs may retain recoverable branches on disk; the gate does not delete those branches or make an upgrade dependent on their archival. A terminal run whose supervisor is still tearing down remains a blocker. Missing/corrupt/busy run state or unpublished `.creating` entries refuse `upgrade_state_unverifiable`. Diagnose/settle them explicitly; there is no indefinite wait, force override or implicit cancellation. A killed keyless creator's staging directory can remain indefinitely; inspect its worker/materializer and git worktree ownership before any manual cleanup, never delete it solely to clear the gate. The gate is not a run-list snapshot: while the exclusive lease is held, no participating `run create` can materialize or publish and `run reattach`/merge-recovery supervisor respawns cannot start. Lock order is admission → idempotency → per-run; no per-run lock may be held while waiting on admission.

**First deployment:** when no Taskfleet binary exists, run the staged admission-aware binary with `TASKFLEET_HOME` pointed at the intended (empty) state home; it can create and hold the gate for installation without depending on an installed executable. Binaries predating this contract do not take admission locks. A new/staged binary cannot fence old direct callers by itself. An upgrade from such a binary requires an externally enforced stop of all old creators, verification that no old process can start creation, then activation; only subsequent upgrades may rely on this gate. Similarly, mixed installations or alternate state roots do not participate. This contract protects Taskfleet worker admissions, not arbitrary non-Taskfleet processes or changes to running worker executable mappings by external package managers.
